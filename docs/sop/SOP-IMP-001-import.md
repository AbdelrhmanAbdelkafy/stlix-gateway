| البند | التفاصيل |
|---|---|

## 2. الغرض

ضبط دورة الاستيراد من أول تحديد الاحتياج لحد إقفال ملف الشحنة محاسبيًا، بحيث تكون كل خطوة موثقة ومسؤوليتها محددة، وبحيث نمنع أسباب التأخير والأرضيات قبل ما تحصل مش بعدها.

## 3. النطاق

**يشمل:** استيراد الخامات (لفات الصاج / stainless steel coils)، المعدات وقطع الغيار، بشحن بحري بالحاويات أو breakbulk، من الصين وأوروبا وأي منشأ آخر.

**لا يشمل:** الشراء المحلي · التصدير · الشحن الجوي (يطبق نفس المنطق مع اختلاف مواعيد ACI) · التعاقد على المعدات كأصول ثابتة (له إجراء منفصل للترسمل).

## 4. التعريفات

| المصطلح | المعنى |
|---|---|
| ACI | Advance Cargo Information — منظومة الإفصاح المسبق عن البضائع، إلزامية للشحن البحري لمصر |
| Nafeza (نافذة) | منصة المستورد المصري لتسجيل الشحنة واستخراج رقم ACID |
| CargoX | المنصة اللي المُصدِّر الأجنبي بيسجل عليها ويرفع منها مظروف مستندات الـ ACI |
| ACID | رقم إقرار الشحنة المسبق — 19 رقم، بيتولد من نافذة بعد تسجيل الشحنة |
| HS Code | بند التعريفة الجمركية للصنف |
| CIF | قيمة البضاعة + الشحن + التأمين — الأساس اللي بتُحسب عليه الضريبة الجمركية في مصر |
| GOEIC | الهيئة العامة للرقابة على الصادرات والواردات |
| BL | Bill of Lading — بوليصة الشحن |
| Free time | فترة السماح المجانية لبقاء الحاوية قبل بداية الأرضيات |

## 5. المسؤوليات

| الدور | المسؤولية |
|---|---|
| مدير المشتريات / الاستيراد | اعتماد المورد والعرض، فتح ملف الشحنة، ومتابعة الجدول الزمني |
| AMEXPRO (مكتب فوشان) | التفاوض مع الموردين الصينيين، متابعة تسجيلهم على CargoX، ومراجعة المواصفات قبل الشحن |
| المسؤول الإداري | تسجيل الشحنة على نافذة، استخراج ACID، متابعة المستندات والمخلص |
| الحسابات | تدبير التمويل، سداد الرسوم، وتحميل تكاليف الاستلام على الشحنة في نما |
| المخلص الجمركي | إعداد البيان الجمركي والإفراج — طرف خارجي بيشتغل بتكليف مكتوب |
| مسؤول المخزن | الاستلام والفحص وإدخال سند الاستلام على نما |

## 6. المتطلبات قبل البدء

- **تسجيل سارٍ على نافذة** للكيان المستورد (بطاقة استيراد سارية، بطاقة ضريبية، سجل تجاري، توقيع إلكتروني).
- **المورد مسجّل ومُوثَّق (KYC) على CargoX** — لو مش موثق، مش هيقدر يرفع مظروف ACI والشحنة هتترفض.
- ملف الشحنة مفتوح باسم موحّد: `IMP-<السنة>-<رقم مسلسل>`.
- تحديد **الكيان القانوني** المستورد قبل أي مستند — الاسم على البوليصة والفاتورة لازم يطابق الكيان اللي هيتحمل التكلفة والضريبة.

## 8. الضوابط الرقابية

| الخطر | الضابط | مين يتحقق |
|---|---|---|
| رفض الشحنة أو توقيفها بسبب اختلاف ACID | مطابقة الرقم على كل مستند قبل الإبحار (خطوة 12) | المسؤول الإداري + مراجعة المدير |
| أرضيات بسبب تأخر المستندات | تاريخ نهاية الـ free time مكتوب في الملف، وتنبيه قبلها بـ 5 أيام | المسؤول الإداري |
| صرف مبالغ للمخلص بدون مستند | **لا صرف إلا مقابل فاتورة أصلية من الجهة المُصدِرة** (خط ملاحي / ميناء / مصلحة) | الحسابات |
| تلاعب في قيمة أو وصف البضاعة في البيان | مطابقة البيان الجمركي مع الفاتورة والـ HS Code قبل التقديم | المسؤول الإداري |
| تحميل تكاليف على الكيان القانوني الغلط | الكيان المستورد محدد قبل إصدار أي مستند، والاسم مطابق على البوليصة والفاتورة | الحسابات |
| فرق وزن أو مواصفة تُكتشف متأخر | الوزن والفحص في نفس يوم الاستلام مع صور | مسؤول المخزن |

## 9. الحالات الاستثنائية

| الحالة | التصرف |
|---|---|
| رفض مظروف ACI من نافذة | تصحيح البيانات وإعادة الرفع فورًا، أو تقديم تظلم — وإبلاغ المورد بوقف الشحن لحد الحل |
| المورد مش موثق على CargoX | وقف الشحن. التوثيق شرط، والبديل الوحيد هو تفويض وكيل الشحن لو النوع بيسمح |
| تأخير في وصول أصل البوليصة | طلب Telex Release طبقًا لـ SOP-IMP-002 قبل بداية الأرضيات مش بعدها |
| أرضيات مستحقة | حصر المبلغ بفاتورة الخط، حسابه مستقل، اعتماد مكتوب قبل الصرف، وتحليل السبب بعد الإفراج |
| فرق في الوزن أو المواصفة | إخطار المورد كتابيًا خلال المدة المسموحة في العقد مع الصور وشهادة الوزن |

## 11. مؤشرات القياس

| المؤشر | الحساب | المستهدف |
|---|---|---|
| زمن الإفراج | من وصول الباخرة لخروج البضاعة (أيام) | يُحدد بعد 3 شهور قياس |
| الأرضيات لكل شحنة | إجمالي الأرضيات ÷ عدد الحاويات | صفر |
| دقة المستندات من أول مرة | الشحنات بدون تصحيح ACI ÷ إجمالي الشحنات | 100% |
| فرق الـ landed cost | الفعلي − التقديري ÷ التقديري | ±5% |

## 12. المراجع

- منصة نافذة (nafeza.gov.eg) — قواعد ومواعيد ACI والرسوم الرسمية.
- منصة CargoX — خطوات تسجيل وتوثيق المُصدِّر ورفع المظروف.
- SOP-IMP-002 — خطوات بوليصة الشحن.

> **تنبيه:** رسوم ومواعيد منظومة ACI ومتطلبات قوالب الفواتير بتتغير بقرارات إدارية. المرجع الملزم هو منصة نافذة في تاريخ الشحنة، مش نسخة الإجراء ده.
