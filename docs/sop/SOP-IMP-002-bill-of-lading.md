## 2. الغرض

ضبط التعامل مع بوليصة الشحن من مرحلة المسودة لحد استخراج إذن التسليم وإرجاع الحاوية، لأن البوليصة هي **سند ملكية البضاعة** — أي غلطة في بياناتها أو في طريقة الإفراج بتكلف أرضيات، أو بتوصل لعدم القدرة على استلام الشحنة أصلًا.

## 3. النطاق

**يشمل:** بوالص الشحن البحري (Original BL · Sea Waybill · Telex Release) لكل الشحنات الواردة، Master و House.

**لا يشمل:** بوالص الشحن الجوي (AWB) · النقل الداخلي · البوالص الصادرة في حالة التصدير.

## 4. التعريفات

| المصطلح | المعنى |
|---|---|
| Original BL | أصل البوليصة — 3 نسخ أصلية عادةً، لازم تُسلَّم للخط الملاحي لاستخراج إذن التسليم |
| Sea Waybill | بوليصة بدون أصول مطبوعة، الإفراج للمرسل إليه المسمى بدون تسليم أصل |
| Telex Release | إخطار من وكيل ميناء الشحن بأن الأصول اتسلمت منه، فيُفرج بدون تقديم أصل |
| تظهير (Endorsement) | توقيع وختم على ظهر البوليصة لنقل الحق فيها — من البنك أو من المرسل إليه |
| Master BL / House BL | الصادرة من الخط الملاحي / الصادرة من وكيل الشحن (Forwarder) |
| إذن التسليم (Delivery Order) | إذن الخط الملاحي للمخلص باستلام الحاوية |
| Detention | غرامة تأخير إرجاع الحاوية الفاضية بعد خروجها |

## 5. المسؤوليات

| الدور | المسؤولية |
|---|---|
| المسؤول الإداري | مراجعة المسودة، متابعة الأصول والتلكس، واستخراج إذن التسليم |
| AMEXPRO (فوشان) | استلام المسودة من المورد ومتابعة تعديلها قبل الإصدار |
| الحسابات | سداد مصاريف الخط الملاحي والأرضيات، ومتابعة رد التأمين على الحاويات |
| البنك | تظهير البوليصة في حالة الاعتماد المستندي أو المستندات مقابل الدفع |
| المخلص الجمركي | استخدام إذن التسليم في سحب الحاوية وإرجاعها |

## 6. المتطلبات قبل البدء

- رقم ACID صادر ومُبلَّغ للمورد (من SOP-IMP-001 خطوة 9).
- تحديد **الكيان القانوني** اللي هيكون Consignee، وبياناته الرسمية بالإنجليزي زي ما هي في السجل.
- تحديد نوع الإفراج المطلوب (أصل / Sea Waybill / تلكس) **قبل** إصدار البوليصة، لأن تغييره بعد الإصدار بيتكلف ويتأخر.
- معرفة الـ free time المتفق عليه مع الخط وتعريفة الأرضيات بالشرائح.

## 8. checklist مراجعة مسودة البوليصة

| البند | اللي بيتراجع عليه |
|---|---|
| Shipper | اسم وعنوان المورد مطابق للفاتورة |
| **Consignee** | الكيان القانوني الصح باسمه الرسمي بالكامل — دي أخطر خانة عندنا بسبب وجود أكثر من كيان |
| Notify Party | بيانات الشركة أو المخلص بإيميل وتليفون شغالين |
| **ACID** | ظاهر وصحيح، 19 رقم، مطابق لنافذة |
| وصف البضاعة | مطابق للفاتورة وللـ HS Code — مش وصف عام |
| الوزن والعدد | مطابق لقائمة التعبئة (Gross / Net / عدد الطرود) |
| أرقام الحاويات والسيل | مطابقة لقائمة التعبئة |
| ميناء الشحن والتفريغ | صحيحين، والتفريغ هو الميناء المخطط له فعلًا |
| Freight Prepaid / Collect | مطابق للـ Incoterm المتفق عليه |
| عدد الأصول الصادرة | معروف ومسجل (عادة 3) |
| تاريخ الشحن (On Board) | مطابق لشروط الاعتماد المستندي لو فيه اعتماد |
| نوع البوليصة | Master ولا House — وواضح مين المُصدِر |

## 9. طريقة الإفراج حسب طريقة السداد

| طريقة السداد | نوع البوليصة المناسب | ملاحظة الضبط |
|---|---|---|
| اعتماد مستندي (LC) | Original BL to order، مُظهَّرة من البنك | مايتمش أي إفراج قبل استلام المستندات من البنك |
| مستندات مقابل الدفع (CAD) | Original BL | البنك مبيسلّمش المستندات إلا بعد السداد |
| تحويل مقدم كامل (TT 100%) | Sea Waybill أو Telex Release | الأسرع والأقل أرضيات، وبيُستخدم مع مورد موثوق فقط |
| تحويل جزئي / رصيد مفتوح | Original BL | البوليصة هي ضمانك، مايتمش تلكس قبل استكمال السداد |

## 10. الضوابط الرقابية

| الخطر | الضابط | مين يتحقق |
|---|---|---|
| تلكس مزيف أو غير مؤكد | التأكيد من وكيل الخط في مصر كتابيًا، مش من المورد | المسؤول الإداري |
| Consignee بالكيان الغلط | تحديد الكيان قبل الإصدار + مراجعة المسودة | المدير |
| أرضيات بسبب تأخر الأصول | تحديد نوع الإفراج قبل الإبحار + عدّاد free time | المسؤول الإداري |
| صرف للخط أو الوكيل بدون مستند | فاتورة أصلية باسم الشركة لكل مبلغ | الحسابات |
| detention بسبب تأخر إرجاع الحاويات | إيصال إرجاع لكل حاوية + متابعة بعد الإفراج | الحسابات |
| البوليصة النهائية مختلفة عن المعتمدة | مطابقة النهائية بالكامل قبل السداد | المسؤول الإداري |

## 11. الحالات الاستثنائية

| الحالة | التصرف |
|---|---|
| فقدان أصل البوليصة | إخطار الخط فورًا، والإفراج ساعتها بيحتاج ضمان بنكي أو تعويض حسب سياسة الخط — الحالة دي تُعرض على المدير مباشرة |
| البوليصة وصلت بدون تظهير البنك | ترجع للبنك للتظهير، وممنوع أي محاولة إفراج بدونه |
| تعديل مطلوب بعد الإصدار (Switch/Amendment) | يطلب من المُصدِر عبر الخط، بمصاريف تعديل معتمدة مسبقًا |
| تغيير ميناء التفريغ | إخطار الخط والمخلص كتابيًا وإعادة مراجعة ACI |
